# Planning walkthroughs

Start with [the Static U lessons](example-static/README.md). Their 15 MATLAB
Live Scripts explain the actual static example from obstacle preparation to
independent validation, with inline calculations, native plots and an
interactive iteration viewer in Step 12.

The lessons and their visible companions are in `example-static/`. Open the
`.mlx` files in MATLAB R2024b and run sections in order. Each lesson runs
independently. The existing numbering skips Step 4.

Executed copies and local verification evidence remain in the ignored
`output/static-u/` folder.
