# Az/El planner method

Users call the public functions at the repository root. This package owns the
HS3 planner behind the stable public result contract:

```matlab
options = planAzElMotion();
result = planAzElMotion(obstacles, initialState, goalState, limits, options);
```

`planAzElMotion("hs3")` is the equivalent explicit defaults request. HS3
success always contains motion produced by its Hermite-Simpson transcription
and sets `SelectedMotionSource="hs3"`.

For moving-target interception, place HS3 options inside `PlannerOptions`.
The root `planAzElMovingTargetIntercept` owns the bounded chronological
fixed-time policy and preserves the common interception result schema.

## Ownership map

```text
+azElPlannerMethods
`-- +hs3
    |-- plan.m                         HS3 planner orchestrator
    |-- resolvePlannerOptions.m        HS3 option owner
    |-- validateTrajectory.m           canonical-validator facade
    `-- +internal/+motion              HS3 transcription and NLP solver
```

`+azElInternal` owns request normalization, endpoint checks, topology
generation, dense envelopes, clustering, convex decomposition, seed-corridor
certification, result schemas, obstacle queries, and polynomial utilities.
The root `validateAzElTrajectory` is the single final validator.

## Dependency and size boundary

HS3 depends on neutral shared contracts and the canonical validator. Its
production MATLAB ownership includes its planner, option resolver, validation
facade, and motion internals; tests, benchmarks, and neutral shared
infrastructure are outside that ownership boundary.

Optimization Toolbox is required because HS3 motion is generated by
`fmincon`. The finite proposal search and local nonlinear solve do not provide
a completeness or global-optimality guarantee.
